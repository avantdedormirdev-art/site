Politique de confidentialité

Dernière mise à jour : septembre 2025

Présentation

AvantDeDormir (« l'application ») est un outil personnel qui publie automatiquement des vidéos sur la chaîne YouTube de son propriétaire via l'API YouTube Data.

Données collectées

L'application ne collecte, ne stocke et ne partage aucune donnée personnelle d'utilisateurs tiers. Elle accède uniquement au compte Google de son propriétaire, dans le seul but de téléverser des vidéos.

Utilisation de l'API Google

L'application utilise le service YouTube Data API v3 avec l'autorisation youtube.upload, exclusivement pour mettre en ligne des vidéos sur la chaîne du propriétaire. L'utilisation des informations reçues des API Google respecte la Google API Services User Data Policy, y compris les exigences d'utilisation limitée (Limited Use).

Partage de données

Aucune donnée n'est vendue, échangée ou transmise à des tiers.

Conservation

Le jeton d'accès Google est conservé localement sur le serveur privé du propriétaire, uniquement pour maintenir la connexion à l'API.
